### Spacing & Radius
- Section padding: `120px 0` desktop, `80px 0` tablet, `60px 0` mobile
- Container max-width: `1280px`, padding: `0 40px` desktop, `0 24px` mobile
- Card radius: `16px` standard, `24px` feature cards, `8px` tags/badges
- Button radius: `6px` (not pill — institutional, not playful)

### Signature Design Element
**The Torii Moment:** The single most memorable element is a stylized, geometric torii gate SVG rendered in thin crimson lines, used as a recurring motif — in the hero as a massive background element, as a section divider watermark, and as the brand logomark. It is never cluttered or busy. When it appears, everything around it goes quiet. This is the design's soul.

### Motion Philosophy
- Scroll-triggered fade-in + translateY(24px → 0) with staggered delays
- Hover: `transform: translateY(-4px)` with `transition: all 0.35s cubic-bezier(0.4, 0, 0.2, 1)`
- No jarring animations. No bouncing. Precision, not playfulness.
- Use `prefers-reduced-motion` media query to disable all animations for accessibility
- Intersection Observer API for all scroll animations

### Shadows
```css
--shadow-card:   0 4px 24px rgba(8,15,26,0.08), 0 1px 4px rgba(8,15,26,0.04);

--shadow-gold:   0 0 0 1px rgba(232,160,26,0.2), 0 8px 32px rgba(232,160,26,0.08);
```
